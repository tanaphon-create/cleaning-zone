# ระบบเช็คเขตทำความสะอาด — โรงเรียนวังจันทร์วิทยา

เว็บสำหรับครูและหัวหน้าเขต ใช้เช็คการทำเขตและเวรห้องรายวัน คิดค่าปรับอัตโนมัติ รับเงิน และสรุปยอดค้าง
หน้าเว็บเป็นไฟล์ HTML/CSS/JS ล้วน (วางบน GitHub Pages ได้ฟรี) ส่วนข้อมูลเก็บใน Google Sheets ผ่าน Apps Script

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css`, `app.js` | หน้าเว็บ |
| `config.js` | ใส่ URL ของ Apps Script (เว้นว่าง = โหมดทดลองในเบราว์เซอร์) |
| `apps-script/Code.gs` | หลังบ้าน วางใน Apps Script |
| `data/` | ข้อมูลที่ดึงจากระบบเดิม (มีชื่อนักเรียน — **ห้ามอัปโหลดขึ้นเว็บ** ถูกกันไว้ใน `.gitignore`) |

## ใครทำอะไรได้
- **ทุกคน (ไม่ต้องเข้าสู่ระบบ):** ดูภาพรวม ผลเช็ครายวัน ยอดค้าง และประวัติรายคน — ดูอย่างเดียว ไม่เห็นชื่อผู้บันทึกหรือหมายเหตุการรับเงิน
  ครูปิดได้ในหน้า **ตั้งค่า** (เปิดให้ทุกคนดู / ซ่อนนามสกุล)
- **หัวหน้าเขต (เข้าสู่ระบบ):** เช็ค รับเงิน กำหนดวันทำเขต เฉพาะเขตตัวเอง
- **ครู (เข้าสู่ระบบ):** ทุกอย่าง ทุกเขต

## สถานะรายวัน
| สถานะ | ความหมาย | เสียเงิน |
|---|---|---|
| มาทำ | มาทำเขต | ไม่ |
| ไม่ทำเขต | มาเรียนแต่ไม่ทำเขต | ใช่ (ตามค่าปรับที่ตั้ง) |
| ขาดเรียน | ไม่มาโรงเรียน | ไม่ |
| ลา | ลาเรียน | ไม่ |

ขาดเวรห้องบันทึกแยก (ปุ่ม "ห้อง") และคิดค่าปรับห้อง

## วันทำเขต
แท็บ **วันทำเขต** (ปฏิทิน แตะเลือกวัน หรือกด "เลือก จ.–ศ. ทั้งเดือน" แล้วแตะวันหยุดออก)
- ครูกำหนด "ทุกเขต (ค่าเริ่มต้น)" และแก้ของเขตใดก็ได้
- หัวหน้าเขตกำหนดวันของเขตตัวเองได้ เขตที่ยังไม่กำหนดใช้ค่าเริ่มต้น และกด "ใช้วันเดียวกับทุกเขต" เพื่อกลับไปใช้ค่าเริ่มต้นได้
- เก็บในชีต `DutyDays` (คอลัมน์ `zoneId` ว่าง = ค่าเริ่มต้น) · ถ้าไม่มีทั้งคู่ ใช้วันในสัปดาห์จากการตั้งค่า

## เซ็ตเวรและวันรายคน
แท็บ **วันทำเขต > เซ็ตเวรและวันของแต่ละคน** (ครู หรือหัวหน้าเขตนั้น)
- สร้างเซ็ต แล้วเลือกวันในสัปดาห์ของแต่ละเซ็ต (มีปุ่มสร้าง 5 เซ็ต จ.–ศ. และแบ่งนักเรียนอัตโนมัติตามเลขที่)
- เลือกเซ็ตให้นักเรียนแต่ละคน หรือ "กำหนดวันเอง" เป็นรายคน · ไม่มีเซ็ต = ทำทุกวันทำเขต
- หน้าเช็คแสดงเฉพาะคนที่มีเวรวันนั้น คนที่ไม่มีเวรอยู่ในหัวข้อพับ "ไม่มีเวรวันนี้" (ไม่ต้องเช็ค ไม่เสียเงิน)
- เก็บในชีต `Sets` และคอลัมน์ `setId`, `days` ของชีต `Students`

## การคิดยอด
- **ยอดค้าง = ยอดยกมาจากระบบเดิม + ค่าปรับใหม่ − เงินที่จ่ายแล้ว**
- ค่าปรับใหม่ = จำนวนครั้ง "ไม่ทำเขต" ที่เช็คในเว็บนี้ หลังวันยกยอด × อัตราในหน้า "ตั้งค่า" (เริ่มต้น 10 บาท/ครั้ง)
- วันที่ขาดที่นำเข้าจากระบบเดิมแสดงเป็นประวัติอย่างเดียว ไม่คิดเงินซ้ำ
- ชีต `Checks` เก็บเฉพาะคนที่ขาด คนที่มาไม่ต้องมีแถว ส่วนแถวที่ `studentId` เป็น `_` แปลว่า "เขตนี้เช็ควันนั้นแล้ว" (ใช้แสดงวันที่ยังไม่ได้เช็ค)

## ติดตั้งจริง
1. สร้าง Google Sheet ใหม่ (บัญชีโรงเรียน) > **ส่วนขยาย > Apps Script** > วางโค้ดทั้งหมดจาก `apps-script/Code.gs`
2. แก้ `ADMIN_INITIAL_PASSWORD` เป็นรหัสของคุณ แล้วเลือกฟังก์ชัน `setup` > **เรียกใช้** (อนุญาตสิทธิ์ครั้งแรก)
3. **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป** · ดำเนินการในฐานะ: *ฉัน* · ผู้มีสิทธิ์เข้าถึง: *ทุกคน*
4. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ `API_URL` ใน `config.js`
5. อัปโหลดไฟล์หน้าเว็บ (ยกเว้น `data/`) ขึ้น GitHub Pages
6. เข้าสู่ระบบด้วย `admin` > **จัดการระบบ > นำเข้าข้อมูลจากระบบเดิม** > เลือก `data/zone-front-building4_raw.json`
7. เพิ่มผู้ใช้หัวหน้าเขต และเลือกเขตที่รับผิดชอบ

แก้ `Code.gs` ภายหลัง: วางโค้ดใหม่ > **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่** (URL เดิม)

## นำเข้าเขตอื่นจากระบบเดิม
ดึงตารางจากลิงก์ของเขตนั้นเป็นไฟล์ `*_raw.json` รูปแบบเดียวกับ `data/zone-front-building4_raw.json`
(`zoneName`, `rangeFrom`, `rangeTo`, `rows` = [เลขที่, ชื่อ, ค่าเขต, ค่าห้อง, "วัน/เดือน, …", เลขประจำตัว(ไม่ใส่ก็ได้)]) แล้วนำเข้าทางหน้าเว็บ
`data/convert.py` แปลงไฟล์เดียวกันเป็น CSV ไว้เปิดใน Excel

## ทดลองในเครื่อง
เว้น `API_URL` ว่าง แล้วเปิดผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ · ครู `admin / admin1234` · หัวหน้าเขต `head1 / demo1234`

## เลขประจำตัวนักเรียน
- ช่อง `code` ในชีต Students (ห้ามซ้ำกันทั้งโรงเรียน เก็บเป็นข้อความ เลข 0 นำหน้าไม่หาย)
- ใส่ได้ที่ **ตั้งค่า > ตารางรายชื่อ** หรือวางหลายคนที่ **ใส่เลขประจำตัวให้รายชื่อเดิม** (`41235 นายสมชาย ใจดี` หรือ `12 41235`)
- ค้นหาด้วยเลขประจำตัวได้ที่หน้าภาพรวม (ทุกเขต) หน้าเช็คเขต และหน้าสรุปยอด
- ถ้าติดตั้ง Sheet ไว้ก่อนมีช่องนี้ ให้รัน `setup` อีกครั้งเพื่อเพิ่มหัวคอลัมน์ `code`
